# Actividad M2A3: HTML Semántico y Validación W3C

En este trabajo se modifico un archivo HTML eliminando el exceso de `<div>` y aplicando etiquetas semánticas de HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`). Se implementó una jerarquía de encabezados correcta y se agregaron etiquetas de texto con significado como `<time>`, `<blockquote>`, `<cite>` y `<address>` para mejorar la accesibilidad y semántica web.
